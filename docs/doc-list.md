# Documentation Registry

- README.md — Project overview: problem statement, client-agent-relay architecture, feature list (including device management), agent stack, and Google Sign-In configuration.
- docs/configuration-profiles.md — Configuration Profiles system: one PowerShell command swaps env-specific files (agent .env, android/local.properties, TLS trust config) between named profiles.
- docs/deployment.md — Central-server deployment to a VPS (deploy-central.ps1, LetsEncrypt or CloudflareOrigin TLS) and per-machine mobaide_agent deployment on Windows (conda), Linux (systemd), and macOS (launchd), including crash-loop supervisor settings.
- docs/email-verification-workflow.md — Email OTP verification flow for email+password registration: happy/unhappy paths, SMTP setup (Mailpit dev, provider prod), rate-limiting knobs, security model.
- docs/password-reset-workflow.md — Password reset for email+password users via OTP-in-app: happy/unhappy paths, per-email + per-IP rate limits, mobile refresh-token revoke, password-changed notification, security model.
- docs/account-deletion-workflow.md — User self-service account deletion (CLA-61): Android Danger-zone flow and mobaide.com web portal share a 14-day soft-delete grace window backed by an audit-log table and a sweeper task; re-auth requirement, three cancellation paths (in-app, portal, email link), schema migration, config knobs, and the public `/portal/delete-account-info` URL submitted to Play Console.
- docs/terminal-view-fork-changes.md — Changelog of edits applied to the vendored Termux `terminal-view` Java sources (`TerminalView.java`, `TerminalViewClient.java`); single source of truth for fork drift on upstream rebase.
- docs/versioning-and-updates.md — Release tag conventions (android-v / agent-v / server-v / proto-v), signed-manifest format, staged-binary auto-updater state machine, install-script + trust-key bootstrap, Android version-gate / Play in-app update / agent-outdated-banner flows, release-please monorepo workflow with PAT caveat, server-side deploy gate, protocol-integrity CI gate (constants + golden + diff guard), end-to-end auto-update verification test.
- docs/release-publishing.md — Install-script publishing pipeline: deploy/install.* and deploy/windows_launcher.py on main → gh-pages branch root → get.mobaide.com. Includes the manual gh-pages sync runbook, what lives on gh-pages (install.sh, install.ps1, windows_launcher.py, CNAME, .nojekyll), and verification steps.
- docs/qr-pairing.md — Agent-initiated QR pairing flow (CLA-50): protocol & data flow, QR payload schema (`MOBA1|...`), relay_url persistence (pairing_tokens column, single source of truth for dispatch and WS-recovery paths), two-phase WS handshake (pending_pairing.json written after "ready" frame), TOFS trust-key pinning on the mobile, re-pair semantics (same-owner rotation vs. different-owner transfer + cascade), operator runbook (install-time, `show-qr`, `re-pair`, headless / SSH-disconnect behaviour), server-side config requirements (`MANIFEST_SIGNING_PRIVATE_KEY`), multi-worker caveat, troubleshooting (503 / 410 / fingerprint mismatch / Windows stdout-silenced v0.1.7–v0.1.8).
- deploy/prod/bootstrap-mobaide.md — One-time VPS bootstrap before deploy-central.ps1 runs: server prerequisites, /opt/mobaide layout, .env seeding, ufw rules, TLS mode choice, optional SQLite backup cron.
- PROTOCOL.md — Wire-contract reference: the single integer protocol_version that gates Android / mobaide_agent / central_server compatibility, application-level WebSocket close codes (4001 auth-failed, 4002 protocol-incompatible, 4010 admin-revoked, 4011 admin-force-disconnect, 4012 agent-transient-offline), and how to bump the version.
- android/CHANGELOG.md — Android app release notes (per android-vX.Y.Z tag).
- mobaide_agent/CHANGELOG.md — mobaide_agent release notes (per agent-vX.Y.Z tag).
- central_server/CHANGELOG.md — central_server release notes (per server-vX.Y.Z tag).
