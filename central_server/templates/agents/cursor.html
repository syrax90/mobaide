Plans you accept with a tap

A Cursor plan arrives as a message and a card with Accept plan and Reject plan. In Plan mode the card also offers Accept and start, which switches to Agent mode and starts the work.

Commands wait for you

A shell command outside Cursor's allowlist asks first: Allow once, Allow always or Reject. Or start with Cursor's own Run Everything — commands your Cursor settings deny still never run.

Sign in on any device

Choose Cursor account in the Sign-in needed card. The Mobaide agent runs cursor-agent login on your computer and shows a sign-in page that works on your phone, with no code to type.

What does Run everything without asking do?

It starts cursor-agent --force, Cursor's own Run Everything: shell commands run without an approval card. Commands your Cursor settings deny still do not run, and file edits never ask in Cursor either way.
