Every launch option

Model, effort and skip permissions — then, under Advanced, fast mode (Opus only), Ultracode, no memory, an appended system prompt and debug logging. Chosen per session, before it starts.

Pick up where you left off

Continue a session lists the Claude Code sessions stored on your computer — also the ones you started by running claude in a terminal — and opens one with its history. Delete the ones you no longer need from the same list.

Trust, exactly like the CLI

Before Claude Code opens a folder it has not trusted, the chat asks Trust this folder? and records your answer in ~/.claude.json, as the CLI does. Permission prompts show Claude Code's own options as buttons.

Can I use plan mode from my phone?

Yes. Switch the mode chip above the message field to plan mode at any time — in a terminal session, Mode (Shift+Tab) on the control-key bar does the same. Claude Code then plans before it changes files, and the plan arrives in the chat as Markdown, as in the demo above.
