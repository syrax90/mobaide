Sign in with GitHub from the phone

Choose GitHub account in the Sign-in needed card. The Mobaide agent runs copilot login --device-code on your computer and shows GitHub's device page and a one-time code.

One switch for full speed

Allow all tools, paths and URLs (dangerous) starts Copilot with allow-all on. The chat shows it, and you can turn it off again in the middle of the session.

Trust that matches the CLI

Copilot loads a folder's hooks and MCP servers, so the chat asks Trust this folder? first and records the answer in Copilot's own trustedFolders list.
