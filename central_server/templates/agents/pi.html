Sign in with the account you have

The Sign-in needed card offers a ChatGPT account or a Claude account, or an OpenRouter, Gemini, OpenAI or Anthropic API key. The Mobaide agent runs Pi's own pi auth login on your computer.

Your extensions come along

Pi's extension commands, prompt templates and skills are in the chat's command list, and extension dialogs turn into approval cards or forms you answer with a tap.

Code Mode

Turn on Code Mode (Pi 1.1.0 or later), and Pi writes a short script that makes several tool calls in one step. The chat shows it as one Run script card with the output and the script.

Does Pi ask before it runs a command?

No — Pi runs its tools without asking, in Mobaide as in a terminal. In a Git workspace you can opt in to a separate worktree for the session, to keep its changes apart, and every tool call shows as a card in the chat.
