Connect a provider from the phone

The OpenCode options screen has a Connect a provider card. It runs opencode auth login on your computer in a terminal session, so you can add a provider without walking back to your desk.

Code Mode, on by default

With OpenCode 2, Code Mode lets OpenCode write a short script that makes several tool calls in one step. The chat shows it as one Run script card with the output and the script. Turn it off for a launch when you want each call on its own.

Auto-approve for long runs

Auto-approve permissions (dangerous) answers each permission request with allow once, so a long run never stops for a tap. Leave it off, and every request waits for you as a card.
