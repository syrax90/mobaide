Plan first, then act

Start in Plan mode has Junie prepare a plan and ask before it changes files. Brave mode (dangerous) runs every command without asking, for that session only.

Your terminal sessions too

Continue a session lists your Junie sessions — including the ones you started in Junie's own terminal interface — and opens one with its history. Delete the ones you no longer need from the same list.

Trust, like the CLI

Junie loads a folder's MCP servers, skills and commands, so the chat asks Trust this folder? first. A folder you already trusted in Junie's terminal interface needs no question.

Can I use Junie Lite in the chat?

No — Junie Lite works only in Junie's terminal interface and in JetBrains apps. Pick another model on the chat's model chip, or run a terminal session to use Junie Lite. If no model can answer, the chat says how to get one.
